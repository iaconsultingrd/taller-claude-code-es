# Taller: Claude Code en español 🇩🇴

Kit abierto para dar un taller práctico de **Claude Code** en español, pensado para comunidades de desarrolladores en República Dominicana y Latinoamérica.

Incluye una guía para el facilitador, ejercicios paso a paso y un proyecto inicial con errores intencionales para que los asistentes los resuelvan junto a Claude.

## ¿Para quién es?

- Desarrolladores que nunca han usado un agente de código.
- Estudiantes de ingeniería en sistemas.
- Equipos técnicos que quieren evaluar Claude Code en su trabajo.

**Duración:** 2 horas · **Nivel:** principiante–intermedio · **Requisitos:** laptop, Python 3.10+ y una cuenta de Claude (Pro, Max, Team, Enterprise o Console).

## Contenido

| Archivo | Qué es |

## Inicio rápido

```bash
# 1. Instalar Claude Code (macOS, Linux, WSL)
curl -fsSL https://claude.ai/install.sh | bash
# Windows PowerShell:  irm https://claude.ai/install.ps1 | iex

# 2. Clonar este repo y entrar al proyecto
git clone https://github.com/iaconsultingrd/taller-claude-code-es.git
cd taller-claude-code-es/proyecto-inicial

# 3. Iniciar Claude Code
claude
```

Luego sigue los ejercicios de [`GUIA.md`](GUIA.md).
